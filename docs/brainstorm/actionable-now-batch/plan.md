# Actionable-now batch - implementation plan

Feature branch: `feat/actionable-now-batch`. TDD per task (write the failing test first, then the change), one atomic conventional commit per task, `bun run fmt` + `bun run lint` green before every commit. Four lanes run in parallel in separate worktrees; no task depends on a task in another lane. Lane ownership is disjoint - if a task seems to need a file another lane owns, stop and escalate to the integrator instead of editing it.

Census notes for all lanes: `tests/core/architecture/write-site-census.test.ts`, `destructive-site-census`, `vault-guard-census`, `entity-read-census`, `visibility-surface-census` and the state-surface census are two-way pins - add or adjust rows in the same commit as the code. CHANGELOG and version are NOT part of any task; osb-pr-prepare handles them.
